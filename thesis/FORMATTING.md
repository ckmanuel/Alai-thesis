# Thesis formatting rules (binding)

This file is the **binding** layout specification for the Velasquez CTA skincare thesis.

**Working file:** `thesis/Velasquez_CTA_Skincare_Thesis_FINAL_2026-10-18.docx` (overwrite in place for small edits).

If chat instructions and this file conflict, **this file wins** for layout.

Sources adapted from the BAELS Thesis Companion, the Verb Tense Matrix, and the formatting conventions used in the related PSAU BAELS thesis memory repos.

---

## Versioning

- Do not inflate draft numbers for format-only or routine edits.
- Overwrite the current working DOCX for small changes.
- New dated or numbered file only when the user explicitly asks, or for a major revision.
- No PDF of the working draft unless the user asks.

---

## Global

| Property | Value |
|----------|--------|
| Font (every run) | **Georgia** |
| Body / headers / references line spacing | **Double** |
| Title page line spacing | **1.5** — do not change title-page blank structure |
| Prefer | Section break (next page) over a bare page break |
| Content spacing | Prefer empty spacer paragraphs for major gaps; keep body paragraph space before/after at 0 |

---

## Title page

- Centered
- Title lines: 14 pt bold
- Other lines: 12 pt regular
- Line spacing: 1.5
- Keep existing blank structure; do not restyle the title page unless asked

---

## Page numbers

| Property | Value |
|----------|--------|
| Position | Header, upper right (right-aligned) |
| Field | PAGE |
| First page of each major section | Hidden (`titlePg` + empty first-page header) |
| Title page | No visible number |
| Font | Georgia 11 |
| Numbering | Continuous across sections (no restart) |

---

## Breaks

- Each major header starts on a **new page**.
- Place the section break on the empty spacer immediately before the major header, not on body text.
- No run-level page breaks inside paragraphs.

---

## Major headers

Examples: INTRODUCTION, METHODOLOGY, RESULTS, ANALYSIS, AND DISCUSSION, CONCLUSION AND RECOMMENDATION, REFERENCES, APPENDICES

| Property | Value |
|----------|--------|
| Font | Georgia **14 bold** |
| Alignment | **Center** |
| Case | ALL CAPS |
| Empty spacers before | 3 plain paragraphs on the new page above the major (section break is separate, before those three) |
| Empty spacers after | 3 |
| Indent | None |
| Pagination | Hidden on the section’s first page |

---

## Minor headers

### Bold subsections

Background of the Study, Statement of the Problem, Research Framework, Significance of the Study, Scope and Limitations, Definition of Terms, Research Context, Research Design, Research Process, Research Corpus, Inclusion Criteria, Exclusion Criteria, Ethical Considerations, Recommendations, etc.

| Property | Value |
|----------|--------|
| Font | Georgia **12 bold** |
| Alignment | Left |
| Indent | None |
| Spacers before | 1 (skip if it already follows a major’s after-spacers) |
| Spacers after | 0 |
| Consecutive minors | If one minor is immediately followed by another, omit the spacer between them |

### Thematic / italic subsections

Part I / Part II / Part III titles, discussion theme heads, italic scope notes

| Property | Value |
|----------|--------|
| Font | Georgia **12 italic** (not bold) |
| Alignment | Left |
| Indent | None |
| Spacers before | 1 (same rule as bold minors) |
| Spacers after | 0 |

---

## Body

| Property | Value |
|----------|--------|
| Font | Georgia **11** |
| Alignment | Justify |
| First-line indent | 0.5 in |
| Empty spacers between body paragraphs | 0 |
| Empty spacers around tables | 1 before the table label (`Table N`), 1 after the last table row |
| Line spacing | Double |

Bullets: left 0.5 in, hanging 0.25 in (not body first-line indent).

---

## Tables

| Property | Value |
|----------|--------|
| Cell font | Georgia **9–11** (match existing corpus tables; prefer 9–11 for density) |
| Cell alignment | Horizontal and vertical center where appropriate |
| Borders | Open-sided (no vertical lines) |
| Header row | Thick top (sz 18) + thin bottom (sz 4) |
| Last row | Thick bottom (sz 18) |
| Middle rows | No cell borders |
| Label (`Table N`) | Georgia 11 bold, left-aligned; keep with next |
| Caption / title under label | Georgia 11 regular, left-aligned |

Do not strip intentional cell fills if the user has already set them.

---

## Definition of Terms

- Term name **bold** through the first period or colon; definition text regular
- Body paragraph rules otherwise (Georgia 11, first-line indent, double spacing)

---

## References

- Georgia 11
- Hanging indent 0.5 in
- APA, alphabetical
- Double line spacing
- 0 space before / after between entries
- Do not split a reference mid-entry across pages when avoidable

---

## Appendices

- Same font and spacing rules as the body for new text
- Preserve existing highlights, strikes, shading, and coding colors unless the user asks to change them
- Appendix major labels follow major-header rules when they start a new section

---

## Intentional bold (keep)

- Major and bold minor headers
- Table numbers on caption lines
- Significance stakeholder labels (e.g. Beauty Product Brands., ELS Students.)
- Research Process step labels when used as structural markers
- Definition of Terms: term name only
- Table header row text

Everything else is regular weight. Clear bold spill on long body paragraphs.

---

## Empty paragraphs

After the title page, empty paragraphs are for controlled spacing only. Prefer the spacer counts above over random blank lines or large space-before/after values on body text.
